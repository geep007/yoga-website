# Asana illustrations — B1 ink-line style

Drop pose illustrations here as PNG (transparent or off-white bg). Filenames must
match the `slug` in `src/PadmaYogaShala.jsx` (const `POSES`). Until a file exists,
the site shows a graceful lotus placeholder — no broken images.

## Required files
- downward-dog.png   — Adho Mukha Svanasana
- tree.png           — Vrikshasana
- side-angle.png     — Utthita Parsvakonasana
- lotus.png          — Padmasana
- mountain.png       — Tadasana
- forward-fold.png   — Paschimottanasana

## Generation prompt (B1 ink-line)
Loose hand-drawn ink illustration of a single person in [POSE], minimalist black
ink line on plain off-white (#F9F5EF) background, expressive uneven line weight,
fashion-sketch / sumi-e feel, full body, calm and graceful, lots of negative space,
no face detail, monochrome black ink only, 4:5 portrait.
--no color, shading, background scene, text, 3D

Keep one consistent line weight across all six so the set reads as a family.
Recommended export: ~800×1000px PNG.
